Feature: KOReader catalog ebook progress compatibility
Status: Complete

Summary:
KOReader compatibility is implemented as a document-hash progress bridge because the KOReader surface only syncs progress by document hash. Full OPDS catalog ebook downloads now record the completed ebook hash for current-user-owned catalog ebooks, and KOReader save/get progress uses that mapping to update catalog-backed user state without exposing upstream source identifiers.
